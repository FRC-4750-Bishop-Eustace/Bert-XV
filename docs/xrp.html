Mecanum XRP Build & Bring-up

Assemble the Mecanum XRP, flash firmware, and drive it from the laptop with RobotPy sim --xrp. Vision lives on the Pi — see the Vision page.

Draft, rewritten Nov 3 2026. Stock XRP kit plus 48 mm mecanum wheels (DFRobot, locked earlier) and Motors 3/4 for a four-wheel drive. Team meets once a week.

Goal

Assemble one Mecanum XRP that the laptop can drive with RobotPy (sim --xrp), ready for PhotonVision pose fusion on the vision page.

Hardware

Piece Choice
Controller (primary) XRP V1 — SparkFun RP2350, USB-C
Spare XRP Beta — Pico W, Micro-USB
Drive 4 geared motors with encoders (kit L/R + Motor 3 + Motor 4)
Wheels 48 mm mecanum (replace the stock 60 mm tires)
Power 4×AA holder into the barrel jack; NiMH recommended
Vision (separate) Pi Zero 2 W + OV9281 — see vision.html; own 5 V USB power bank, not the AA pack

Firmware

Release used: xrp-wpilib-firmware v2.1.0 (wpilibsuite/xrp-wpilib-firmware).

  1. Download the UF2 for your board (V1 file has no -beta in the name; Beta file includes -beta).
  2. Hold BOOT (V1) or BOOTSEL (Beta), plug USB, release after the mass-storage drive appears.
  3. Drag the UF2 onto the drive; the board reboots.
  4. Batteries in, switch on. Join Wi-Fi XRP-<id> / password xrp-wpilib. Robot IP 192.168.42.1, code port 3540, web UI http://192.168.42.1:5000.

RobotPy (laptop)

pyproject.toml:

[tool.robotpy]
robotpy_version = "2026.2.1.1"
components = ["xrp", "apriltag"]
requires = ["photonlibpy"]

python -m robotpy sync
HALSIMXRP_HOST=192.168.42.1 HALSIMXRP_PORT=3540 python -m robotpy sim --xrp

Robot code runs on the laptop. The XRP only receives motor commands over the XRP link.

Mecanum drive sketch

WPILib motor channels: 0 = front-left, 1 = front-right, 2 = rear-left, 3 = rear-right (confirm against your cable labels). Invert right-side motors before building MecanumDrive. Wheel diameter constant: 0.048 m.

import os
os.environ.setdefault("HALSIMXRP_HOST", "192.168.42.1")
os.environ.setdefault("HALSIMXRP_PORT", "3540")

import wpilib, xrp
from wpilib.drive import MecanumDrive
from wpimath.kinematics import MecanumDriveKinematics, MecanumDriveWheelPositions
from wpimath.estimator import MecanumDrivePoseEstimator
from wpimath.geometry import Translation2d, Pose2d, Rotation2d
from wpimath.units import inchesToMeters

# Track / wheelbase: measure your chassis; placeholders below.
FL = Translation2d(inchesToMeters(3.0), inchesToMeters(3.0))
FR = Translation2d(inchesToMeters(3.0), inchesToMeters(-3.0))
RL = Translation2d(inchesToMeters(-3.0), inchesToMeters(3.0))
RR = Translation2d(inchesToMeters(-3.0), inchesToMeters(-3.0))

class MyRobot(wpilib.TimedRobot):
    def robotInit(self):
        self.fl = xrp.XRPMotor(0)
        self.fr = xrp.XRPMotor(1)
        self.rl = xrp.XRPMotor(2)
        self.rr = xrp.XRPMotor(3)
        self.fr.setInverted(True)
        self.rr.setInverted(True)
        self.drive = MecanumDrive(self.fl, self.rl, self.fr, self.rr)

        self.fl_enc = wpilib.Encoder(4, 5)
        self.fr_enc = wpilib.Encoder(6, 7)
        self.rl_enc = wpilib.Encoder(8, 9)
        self.rr_enc = wpilib.Encoder(10, 11)
        m_per_count = 3.14159265 * 0.048 / 585.0
        for e in (self.fl_enc, self.fr_enc, self.rl_enc, self.rr_enc):
            e.setDistancePerPulse(m_per_count)

        self.gyro = xrp.XRPGyro()
        self.kin = MecanumDriveKinematics(FL, FR, RL, RR)
        self.pose = MecanumDrivePoseEstimator(
            self.kin, Rotation2d(), self._wheels(), Pose2d()
        )

    def _wheels(self):
        return MecanumDriveWheelPositions(
            self.fl_enc.getDistance(),
            self.fr_enc.getDistance(),
            self.rl_enc.getDistance(),
            self.rr_enc.getDistance(),
        )

    def teleopPeriodic(self):
        stick = wpilib.XboxController(0)
        self.drive.driveCartesian(
            -stick.getLeftY(), stick.getLeftX(), stick.getRightX()
        )
        self.pose.update(self.gyro.getRotation2d(), self._wheels())

Vision measurements are added later with self.pose.addVisionMeasurement(...) — see vision.html.

First-drive checklist

  1. Flash firmware; join the XRP AP; run sim --xrp.
  2. Confirm IMU values move in the sim GUI when you tilt the robot.
  3. Drive forward / strafe / rotate; confirm encoder distances grow in the expected direction.
  4. Measure track width and wheelbase; replace the placeholder Translation2d values.
  5. Do not stream video over the XRP AP — pose numbers only (vision page).
