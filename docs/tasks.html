Q10 / Q12

NetworkTables bring-up (Q10 step 3 / Q12)

Architecture

The XRP never speaks NetworkTables. The RobotPy program on the Mac is the NT4 server; the Pi Zero (PhotonVision, 10.0.1.3) and the dashboard are NT clients. The XRP (10.0.1.4) only exchanges motor/sensor packets with the Mac over UDP 3540 (relayed via localhost:3541). Source: BERT-XV-Preseason commit 16b9372.

Remaining steps

  1. On the Pi, ensure run-photonvision.sh no longer passes --disable-networking. Standard config
  2. PhotonVision Settings → Networking: keep NT server off; replace team 4750 with the Mac’s BERT-Test IP (team 4750 resolves to 10.47.50.2, which is not on this LAN). Standard config
  3. Reserve the Mac’s IP on the AirPort. Standard config
  4. Allow incoming TCP 5810 (NT4) and UDP 5810 (PhotonLib time sync) on the Mac firewall. Standard config
  5. Launch: XRP_PROFILE=profiles/<station-profile>.json .venv/bin/python -m robotpy run-xrp --host 127.0.0.1 --port 3541; verify lsof -nP -iTCP:5810 shows *:5810. Standard config
  6. Point Glass, Elastic, or AdvantageScope at localhost (not a team number); a photonvision table should appear. Standard config
  7. In robot code, create PhotonCamera("<exact PhotonVision UI camera name>") on the default NT instance (do not use vision.photon.open_camera() — it starts a second server) and connect PhotonAdapter in RobotContainer. The template still says xrp-camera-PENDING. Standard photonlibpy + existing custom adapter wiring
  8. Finish calibration, the mount profile, and the clock-sync check before vision poses are accepted. Calibration

Gotchas

  • robot.local / team-number lookup don’t apply without a roboRIO (the Pi is bert-vision.local).
  • NT4 is TCP 5810, not NT3’s 1735.
  • PhotonVision must stay an NT client.
  • PhotonVision doesn’t start on boot — start it manually.
  • No usable poses until calibration and 3D settings are done.

Unverified on live hardware: launcher flags, the NT server toggle, the exact camera name, the Mac IP and firewall, and whether the server binds *:5810.
